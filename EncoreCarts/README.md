# EncoreCarts

Мод перемещения на повозках для **NeoForge 1.21.1** (21.1.220 и новее), Java 21.

## Сборка

```bash
./gradlew build        # jar: build/libs/encorecarts-<version>.jar
./gradlew test         # юнит-тесты цены и размена монет
./gradlew runClient    # dev-клиент (с Xaero: -Pdev_with_xaero=true)
./gradlew runServer    # dev-сервер
```

## Как пользоваться

1. Админ берёт **Повозку** из креативной вкладки (ставить/убирать может только оператор, уровень — `adminPermissionLevel` в конфиге).
2. ПКМ по земле → окно: название точки + галочка «Глобальная» (видна всем); без галочки игрок должен сам дойти до точки и поговорить с извозчиком.
3. Рядом с повозкой стоит NPC-извозчик. ПКМ по нему → список открытых точек **текущего измерения** с ценой; точки, на которые не хватает денег, неактивны.
4. Поездка: затемнение → один из 10 ракурсов повозки → затемнение → игрок на точке назначения. Остальные игроки видят только исчезновение/появление.

Вся логика (доступ, измерение, расстояние, цена, списание, телепорт) выполняется на сервере; клиентский код изолирован в пакете `client` и на выделенном сервере не загружается.

## Цена

`ceil(расстояние / 100) × copperPer100Blocks` (по умолчанию 15 медных). Баланс считается по всем номиналам (100 c = 1 i, 100 i = 1 g, 100 g = 1 p), при списании старшие монеты разменываются.

## Команды (`/carts`, уровень оператора)

| Команда | Действие |
|---|---|
| `/carts setcost <count>` | цена в медных за 100 блоков, сохраняется в `config/encorecarts-common.toml` |
| `/carts open <user> <location name>` | открыть точку игроку (автокомплит имён точек) |
| `/carts close <user> <location name>` | закрыть точку игроку |
| `/carts list`, `/carts remove <location name>` | список / удаление точек |

Точки и доступ игроков хранятся в данных мира и переживают перезапуск.

## Валюта (EncoreCraft)

Весь доступ к кошельку идёт через `economy.CurrencyService` (`Economy.setService(...)`). Сейчас используется `EncoreCraftCommandWallet`: он вызывает `addCoinPlayer / delCoinPlayer / infoCoinPlayer` и разбирает вывод (шаблоны команд и слова для разбора — секция `[economy]` конфига).

Пока EncoreCraft не установлен, мод регистрирует **тестовые** команды с теми же именами (`economy.stubWalletCommands`), баланс хранится в `data/encorecarts_test_wallets.dat`. Когда будет Java API EncoreCraft, достаточно новой реализации `CurrencyService`.

## Модели

Модели — `.bbmodel` (Blockbench) в `assets/encorecarts/bbmodel/`, привязка — `assets/encorecarts/encorecarts_models/*.json`. Чтобы заменить повозку, положите свой `cart.bbmodel` (с текстурой внутри) на место заглушки — код менять не нужно. Извозчик построен на присланных `classic.bbmodel` / `slim.bbmodel` с их анимациями.

## Xaero's World Map

Необязательная интеграция: иконка на каждой открытой игроку точке, без подписи; название — только в подсказке при наведении. Без Xaero или EncoreCraft мод запускается без соответствующей интеграции.

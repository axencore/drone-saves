# EncoreCarts

Перемещение на повозках между станциями для NeoForge 1.21.1. Это сбалансированная альтернатива Waystones:
поездки платные, работают только внутри текущего измерения, а скрытые станции нужно сначала найти.

* Minecraft 1.21.1, NeoForge **21.1.220 и новее** (сборка идёт против 21.1.220, проверено на 21.1.220, 21.1.230 и 21.1.265).
* Java 21.
* Мод нужен и на сервере, и на клиентах. Вся логика (цены, оплата, доступ, телепортация) выполняется на сервере.
* Необязательные зависимости: EncoreCraft (кошелёк) и Xaero's World Map (иконки на карте).
  Без них мод запускается и работает.

## Сборка

```bash
./gradlew build          # jar: build/libs/encorecarts-1.0.0.jar, заодно запускает юнит-тесты
./gradlew runClient      # клиент для разработки
./gradlew runServer      # выделенный сервер для разработки
./gradlew runClient -Pdev_with_xaero=true   # клиент вместе с Xaero's World Map
```

## Как пользоваться

### Установка станции (только админ)
1. Предмет **«Повозка»** есть только в творческом инвентаре (вкладка «Инструменты», у операторов ещё и «Операторские»).
   Крафта нет.
2. ПКМ по верхней грани блока. Повозка встаёт лошадью туда, куда смотрит админ (с шагом 45°).
   Сервер проверяет, что админ в творческом режиме и у него есть уровень прав `adminPermissionLevel` (по умолчанию 2).
3. Открывается окно, где нужно:
   * ввести **название точки перемещения** (обязательно, до 32 символов, уникально без учёта регистра);
   * отметить галочку **«Доступна всем игрокам»**. Если галочка снята, точка скрыта, и игрок должен сам дойти до станции
     и поговорить с извозчиком, чтобы она открылась.
4. Рядом с повозкой появляется **извозчик**: классическая или slim-модель, выбирается случайно.

Удалить станцию можно ударом по повозке или извозчику в творческом режиме, удерживая Shift, или командой `/carts remove`.
Убитые командами или очисткой сущностей извозчик и повозка через несколько секунд появляются снова: станция удаляется
только явным действием админа.

### Поездка
* ПКМ по извозчику (или по повозке) открывает меню со списком открытых игроку станций **этого же измерения**.
* У каждой станции видны расстояние и цена. Если денег не хватает, строка серая с красной ценой, и выбрать её нельзя.
* Сервер заново проверяет доступ, измерение, расстояние до станции и баланс, после чего списывает деньги.
* Катсцена длится около 5 секунд, и видит её только сам путешественник: затемнение, повозка в пути
  (один из 10 ракурсов), затемнение, плавное появление уже на станции назначения.
* Для остальных игроков путешественник просто исчезает и появляется у станции назначения. Пока идёт катсцена, он
  неуязвим и не может действовать.
* Если игрок умер во время поездки или его перенесло в другое измерение, поездка отменяется и деньги возвращаются.
  Если он вышел из игры, то сохраняется уже в точке назначения.

### Цена
`15 медных × количество начатых отрезков по 100 блоков` горизонтального расстояния между станциями.
1–100 блоков стоят 15, 101–200 блоков стоят 30, 250 блоков стоят 45. Цена меняется командой `/carts setcost`.

### Ракурсы катсцены
| № | Ракурс |
|---|--------|
| 0 | сбоку, медленный проезд камеры вдоль повозки |
| 1 | изнутри повозки, из-за плеча самого игрока (его скин и экипировка) |
| 2 | «боковое зеркало»: камера у левого борта смотрит назад вдоль фургона на уходящую дорогу |
| 3 | спереди, повозка надвигается на камеру |
| 4 | с обочины, повозка проезжает мимо |
| 5 | «кран»: высокий план, камера поднимается |
| 6 | облёт вокруг повозки |
| 7 | низкий план у колёс |
| 8 | портрет извозчика: камера у лошади смотрит назад на него и фургон |
| 9 | отправление со станции, камера наезжает |

Ракурс выбирает сервер случайно. В клиентском конфиге можно закрепить нужный (`forcedShot`), это удобно при съёмке.
Дорогу повозка выбирает сама: ищет самое ровное и свободное направление рядом с направлением станции и едет по рельефу.

## Команды
Нужен уровень прав `adminPermissionLevel` (по умолчанию 2). Все изменения сразу записываются на диск.

| Команда | Что делает |
|---------|------------|
| `/carts setcost <count>` | цена в медных за каждые 100 блоков, сохраняется в `config/encorecarts-common.toml` |
| `/carts open <user> <location name>` | открыть станцию игроку (или нескольким через селектор) |
| `/carts close <user> <location name>` | закрыть станцию игроку. Закрытая админом станция не откроется снова при посещении |
| `/carts list` | все станции, их координаты и режим |
| `/carts remove <location name>` | удалить станцию |

У `<location name>` работает автодополнение по существующим станциям, а названия с пробелами пишутся как есть:
`/carts open Steve Северная застава`.

## Где хранятся данные
* `config/encorecarts-common.toml` (сервер): цена, права, команды кошелька.
* `config/encorecarts-client.toml` (клиент): закреплённый ракурс, кинорамка, звуки, иконки на карте.
* `world/data/encorecarts_stations.dat`: станции и доступ игроков (открыто или закрыто админом, найдено игроком).
  Это данные мира, а не конфиг: они переезжают вместе с миром и попадают в его бэкапы.
  Файл записывается сразу после каждого изменения.

## Валюта (EncoreCraft)
Вся работа с деньгами изолирована за интерфейсом `economy.CurrencyService`:
`balance(player)`, `withdraw(player, copper)`, `deposit(player, copper)`. Остальной код вызывает только `Economy.service()`.

Сейчас используется `EncoreCraftCommandWallet`, который работает через серверные команды EncoreCraft:
1. читает кошелёк командой `infoCoinPlayer <ник>` и разбирает её вывод;
2. считает оплату в медных: младшие монеты тратятся первыми, при нехватке разменивается минимально достаточная старшая
   (1 платиновая = 100 золотых = 10 000 серебряных = 1 000 000 медных), сдача возвращается младшими монетами;
3. сначала снимает монеты через `delCoinPlayer`, потом выдаёт сдачу через `addCoinPlayer`. Если команда не прошла,
   уже сделанные изменения откатываются, и лишние деньги не появляются;
4. перечитывает кошелёк и пишет предупреждение в лог, если итог не совпал с расчётом.

Шаблоны команд и слова, по которым ищутся монеты в выводе `infoCoinPlayer`, настраиваются в `[economy]`
файла `config/encorecarts-common.toml`. Точный формат вывода EncoreCraft пока неизвестен, поэтому разбор понимает
`c=12`, `Медные: 12`, `Медные монеты: 12`, `12 медных` и `§6Gold§r: 1 200`.

**Переход на Java API EncoreCraft:** нужно реализовать `CurrencyService` поверх API и вызвать
`Economy.setService(new EncoreCraftApiWallet())` в конструкторе мода. Другой код менять не придётся.

### Тестовый кошелёк
Если EncoreCraft не установлен (`encoreCraftModIds`) и включён `stubWalletCommands`, мод регистрирует **тестовые**
команды с теми же именами и синтаксисом. Деньги хранятся в `world/data/encorecarts_test_wallets.dat`.
Так можно проверить всю цепочку оплаты без EncoreCraft:

```
/addCoinPlayer Steve g 1        # 1 золотая
/infoCoinPlayer Steve
```

Когда EncoreCraft установлен или его команда `infoCoinPlayer` уже зарегистрирована, тестовые команды не создаются.

## Xaero's World Map
Если установлен Xaero's World Map (проверено на 1.44.2–1.47.0), на полноэкранной карте появляются иконки станций,
**открытых этому игроку**, причём только станций текущего измерения карты. Подписей у иконок нет: название станции
видно только во всплывающей подсказке при наведении. С Xaero Regions иконки не конфликтуют: регионы рисуются
отдельно. Список открытых станций присылает сервер, и он обновляется при открытии, закрытии и удалении станции.

## Модели

### Как устроен рендер
Модели загружаются из файлов Blockbench (`.bbmodel`) встроенным загрузчиком. Он поддерживает группы с поворотами,
кубы (per-face UV, box UV, inflate, поворот), mesh-элементы, встроенные текстуры и анимации (linear, catmullrom,
bezier, step, простые Molang-выражения). Скрытые и неэкспортируемые элементы пропускаются.

Связь модели с игрой описана в JSON-файлах `assets/encorecarts/encorecarts_models/*.json`, а не в коде:

```jsonc
// cart.json
{
  "model": "encorecarts:bbmodel/cart.bbmodel",
  "scale": 1.0,                      // 16 px модели = 1 блок
  "offset": [0, 0, 0],               // [вправо, вверх, вперёд] в блоках
  "animations": { "idle": "idle", "moving": "moving" },   // роль -> имя анимации в .bbmodel
  "wheel_bones": ["wheel_front_left", "wheel_front_right", "wheel_rear_left", "wheel_rear_right"],
  "wheel_radius": 0.5,               // для скорости вращения колёс (в блоках)
  "seats": { "driver": [-0.2, 1.25, 1.28], "passenger": [0.25, 1.0, -0.31] },  // верх сидений
  "horse": { "enabled": true, "offset": [0, 0, 2.75], "scale": 1.0 }           // ванильная лошадь в упряжке
}
```

Модель смотрит вперёд в сторону −Z (это «North» в Blockbench), центр повозки находится на земле в точке (0, 0, 0).

### Замена повозки
1. Сохраните свою модель как `src/main/resources/assets/encorecarts/bbmodel/cart.bbmodel` (или укажите другой путь в `"model"`).
2. Если в ней есть группы колёс, перечислите их в `wheel_bones`. Для анимаций стоянки и движения назовите их
   `idle` и `moving` или пропишите свои имена в `"animations"`.
3. Поправьте `seats`, то есть высоту и положение сидений извозчика и пассажира, и `horse.offset`.
   Если лошадь уже есть в модели, поставьте `"enabled": false`.

Код при этом не меняется. То же самое можно сделать ресурспаком, а F3+T перезагружает модели прямо в игре.
glTF не поддерживается: нужен экспорт проекта Blockbench (`.bbmodel`).
Сейчас `cart.bbmodel` — заглушка: крытый фургон с тентом, скамьями, грузом, фонарём, оглоблями и 4 колёсами.

### Извозчик
Используются ваши `classic.bbmodel` и `slim.bbmodel` вместе с их анимациями:
`idle` на стоянке, `hello` при обращении игрока, `sit` на козлах во время катсцены, `face-eyesClosed` для моргания.
Голова поворачивается к игроку. Отладочные группы (`DEBUG_OBJECTS`, `ItemDebugVisibles*`) скрыты в
`coachman_*.json`. Скин извозчика лежит в `textures/entity/coachman/{classic,slim}.png` по раскладке шаблона
из ваших моделей. Чтобы заменить скин, достаточно подменить PNG или строку `"textures"` в JSON.

## Устройство кода
```
com.encorecraft.encorecarts
├── EncoreCarts                 общий вход (регистрация, сеть, конфиг, серверные события)
├── command/CartsCommand        /carts
├── config/CartsConfig          серверный конфиг
├── economy/                    CurrencyService, размен монет, тестовый кошелёк
├── entity/                     CartEntity, CoachmanEntity (без клиентских классов)
├── item/CartItem               установка станции
├── mixin/                      скрытие путешественника от других игроков, камера катсцены (client)
├── network/                    пакеты; клиентский обработчик подключается только на клиенте
├── station/                    станции, доступ, установка, самовосстановление
├── travel/                     цена, проверки, сессии поездок, телепорт
└── client/                     ТОЛЬКО клиент: @Mod(dist = CLIENT), экраны, рендер, катсцена, Xaero
```
Код из `client/` загружается только клиентским входом `EncoreCartsClient` (`@Mod(dist = Dist.CLIENT)`).
Общий код ссылается на клиент только через интерфейс `ClientPacketHandler`, поэтому выделенный сервер
клиентские классы не загружает. Классы Xaero используются только внутри `client/compat/xaero` и только если мод установлен.
